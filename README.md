# MushTato

MushTato is a free, open-source, cross-platform Python GUI client for MUD/MUSH
games, combining Potato's GUI features with TinyFugue-style triggers/macros —
reimagined using sandboxed Python scripting instead of a custom scripting
language.

- **New here?** See `INSTALL.md` to download and run MushTato.
- Something not working? See `TROUBLESHOOTING.md`, or use the in-app
  **Help** menu once MushTato is running.
- See `SPEC.md` for the full project vision, `CLAUDE.md` for
  contributor/session guidance, `CHANGELOG.md` for phase-by-phase history,
  and `CREDITS.md` for attribution to Potato and TinyFugue.
